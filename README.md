An online banking System developed using Spring framework.
A simple banking web application to create user account, perform transactions, display statement and authorize credit card transactions.
Technology Stack:
Front-end & UI - JSP, JavaScript and AJAX
Back-end - Java 18, J2EE (Servlets), Spring Framework, Spring MVC, Lombok
Data Access & Persistence - Spring ORM (Hibernate), MySQL
Data Exchange & Formats - JSON, XML
Build Tools - Maven, Apache Tomcat, GitHub
